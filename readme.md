## 🧰 Tooling

- **Editor**: [Obsidian](https://obsidian.md) with community plugins including Git version control, Quick LaTeX, Claude sidebar, Markdown linter, and TikZ rendering.
- **Sync**: A `git-auto-push.bat` script stages all changes, commits, and pushes to both GitHub and Gitee in one click.

## 🚀 Getting Started

1. Clone the repo.
2. Open the folder as an **Obsidian vault** to enable graph view, backlinks, and plugin features.
3. Or simply browse the Markdown files in any text editor.

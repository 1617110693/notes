`scikit-learn`（即 `sklearn`）是整个机器学习界最标准的“大一统”武器库。它的模块划分极其有规律，基本是按照**机器学习的经典标准工作流**来组织的。

为了让你在遇到它们时能瞬间在脑海里“对号入座”，我们用工作流的顺序，把 `sklearn.*` 下最核心的 6 大王牌军团为你全部列出来：

## 🏗️ 第一阶段：数据预处理与特征工程（洗原材料）

数据刚加载进来时，往往有缺失值、汉字文本、或者数据尺度不统一，需要用它们来“调教”。

| **模块名**                      | **它是干什么的**             | **里面藏着什么核心武器**                                     |
| ------------------------------- | ---------------------------- | ------------------------------------------------------------ |
| **`sklearn.preprocessing`**     | **特征预处理**（缩放、编码） | * `StandardScaler`（Z-score 标准化，高数里的 $\mu=0, \sigma=1$） * `MinMaxScaler`（归一化到 $0 \sim 1$ 区间） * `OneHotEncoder`（你刚学的**独热编码**工业级版） * `LabelEncoder`（标签编码 $0,1,2,3$） |
| **`sklearn.impute`**            | **缺失值填充**               | * `SimpleImputer`（用平均值、中位数或众数自动填补缺失的 `NaN`） |
| **`sklearn.feature_selection`** | **特征选择**（降维、删特征） | * `VarianceThreshold`（方差过滤，删掉那些一成不变的废特征）  |
| **`sklearn.decomposition`**     | **矩阵分解与降维**           | * `PCA`（主成分分析，数学里的**特征值分解**，把几百列特征强行压缩成几列） |

## 🤖 第二阶段：五大核心算法军团（排兵布阵）

这是真正的模型库。根据你的业务场景（是预测连续数字、还是分类、还是聚类），去对应的山头搬兵：

### 1. 连续数字预测 ── 线性回归军团

| **模块名**                 | **里面藏着什么核心武器**                                     | **什么时候用** |
| -------------------------- | ------------------------------------------------------------ | -------------- |
| **`sklearn.linear_model`** | * `LinearRegression`（最基础的**普通线性回归**） * `Ridge`（岭回归，加了 $L_2$ 正则化） * `Lasso`（Lasso回归，加了 $L_1$ 正则化，能把无用特征系数变 $0$） * `LogisticRegression`（**逻辑回归**，名字叫回归，其实是**分类**战神，比如预测泰坦尼克号生死） |                |

### 2. 传统机器学习王者 ── 树模型与集成算法军团

| **模块名**             | **里面藏着什么核心武器**                                     | **什么时候用**                                               |
| ---------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| **`sklearn.tree`**     | * `DecisionTreeClassifier`（分类决策树） * `DecisionTreeRegressor`（回归决策树） | 经典的 IF-THEN 树状逻辑构建                                  |
| **`sklearn.ensemble`** | * `RandomForestClassifier`（你刚才教程里看到的**随机森林分类器**） * `RandomForestRegressor`（随机森林回归器） * `GradientBoostingClassifier`（梯度提升树 GBDT） | **工业界大杀器**。集思广益，用几百棵树投票来决定最终结果，效果极稳。 |

### 3. 其他经典数学流派算法

| **模块名**              | **里面藏着什么核心武器**                            | **它的数学直觉**                                             |
| ----------------------- | --------------------------------------------------- | ------------------------------------------------------------ |
| **`sklearn.svm`**       | * `SVC`（支持向量分类机） * `SVR`（支持向量回归机） | 数学技巧极强。在高维空间里寻找一个**最佳超平面**，把两拨人完美隔开。 |
| **`sklearn.neighbors`** | * `KNeighborsClassifier`（KNN 近邻算法）            | “近朱者赤，近墨者黑”。看距离你最近的 $K$ 个邻居是谁，你就归为哪一类。 |
| **`sklearn.cluster`**   | * `KMeans`（K均值聚类）                             | **无监督学习**。数据没有标签（没有正确答案），让算法自己去把数据扎堆、分成 $K$ 个圈子。 |

## 🧪 第三阶段：模型评估与调参（阅兵与质检）

模型训练完了（`.fit()` 之后），我们得看看它到底准不准，或者帮它寻找最佳的数学超参数。

| **模块名**                    | **它是干什么的**     | **里面藏着什么核心武器**                                     |
| ----------------------------- | -------------------- | ------------------------------------------------------------ |
| **`sklearn.model_selection`** | **数据集切分与调参** | * `train_test_split`（黄金函数：把数据按 $8:2$ 随机切分成**训练集**和**测试集**） * `GridSearchCV`（**网格搜索交叉验证**：暴力枚举所有参数组合，帮你找出能让模型考最高分的那个参数配置） |
| **`sklearn.metrics`**         | **模型效果评估指标** | * `accuracy_score`（分类准确率） * `confusion_matrix`（混淆矩阵，看模型具体把哪些好人错判成了坏人） * `classification_report`（一键打印出精确率、召回率、F1-score 战报） * `mean_squared_error`（MSE，回归任务里最标准的**均方误差**） |

### 💡 终极一行流公式 ── 整个 `sklearn` 的行为艺术

未来你在任何地方看到庞大的 `sklearn` 代码，它们的底层逻辑全部被压缩成了以下四行（**甚至连函数名字都高度统一**）：

Python

```
from sklearn.ensemble import RandomForestClassifier  # 1. 从对应的山头搬兵
model = RandomForestClassifier(n_estimators=100)      # 2. 实例化模型，给它配置参数

model.fit(X_train, y_train)                           # 3. 喂数据，让模型疯狂训练（学高数）
predictions = model.predict(X_test)                    # 4. 让学成归来的模型去预测未知的数据
```
